# Waste Wearable Art

Student waste wearable art from PERF 156: Dress in World Cultures, Texas A&M University (Spring 2023 to Spring 2026).

A static website published with GitHub Pages. Pieces are credited by group and semester only.

- `index.html` is generated by `build.py` in the project's working folder; edit the data there and rebuild.
- `img/` holds web-sized runway photos.

## Editing

Piece data is in `tools/pieces_src.py` and the photo, category and layout settings are in `tools/build.py` and `tools/template.html`. Run `python3 tools/build.py` to regenerate `index.html`.
